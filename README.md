# COP31 (Godot 4.x)

1. Godot 4.2+ ile `project.godot` dosyasını aç, F5.
2. Kontroller: A/D hareket, Boşluk/W zıpla, J/X saldır. Çöp itemlerini topla, mavi geri dönüşüm kutularına götür, boss kapısının kilidini aç.
3. Hiç harici asset yok: her şey kodla çizilir. Sprite/ses eklemek için player.gd, enemy.gd vb. içindeki `_draw()` yerine Sprite2D koyabilirsiniz.
